# Aequitas AI — Frontend

React (Vite) + Tailwind CSS.

## Local dev

```
npm install
npm run dev        # http://localhost:5173
```

## Build

```
npm run build
```

Talks to the backend at the URL set by `VITE_API_URL` (add this to a `.env`
file here once the backend has real endpoints to call — Module 0 has none yet).
